# 多模型协作台（浏览器版）· Beta V1.1.0 Explorer

在线使用：打开本仓库的 GitHub Pages 网址即可。

- 指挥官拆解任务 → 多家大模型按特长分工 → 换一家模型交叉审稿 → 汇总成品
- 点右上角钥匙图标「API 设置」填自己的 API Key；有哪家的就填哪家，没填的自动不参与
- 支持 DeepSeek、阶跃星辰 Step、Kimi。智谱 GLM 的接口不允许浏览器直接调用，这里用不了
- Key 只保存在你自己的浏览器里，请求由浏览器直接发给各家 API，不经过任何中转服务器；
  默认关掉页面就忘掉 Key，勾选「记住」才会长期保存。别在公用电脑上勾选「记住」
- 先用「模拟」模式看流程，不联网、不花钱
