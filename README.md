# 多模型协作台（浏览器版）· Beta V1.2.0 Explorer

在线使用：https://theshyocean.github.io/multi-llm/

- 指挥官拆解任务 → 多家大模型按特长分工 → 换一家模型交叉审稿 → 汇总成品
- 点右上角钥匙图标「API 设置」：填自己的 API Key，再点「获取列表」从各家 API 拉取可用型号，挑选后加进「模型阵容」；
  同一家可以加多个模型，没填 Key 的自动不参与
- 支持 DeepSeek、阶跃星辰 Step、Kimi、阿里百炼（通义千问）、硅基流动、百度千帆（文心）、MiniMax。
  智谱 GLM 的接口不允许浏览器直接调用，这里用不了
- Key 只保存在你自己的浏览器里，请求由浏览器直接发给各家 API，不经过任何中转服务器；
  默认关掉页面就忘掉 Key，勾选「记住」才会长期保存。别在公用电脑上勾选「记住」
- 先用「模拟」模式看流程，不联网、不花钱
